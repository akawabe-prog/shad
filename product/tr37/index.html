Description

世界中のバイヤーより支持されている高い機能性とスタイリッシュなデザイン。SHAD(シャッド)ブランドは1973年にスペインのバルセロナで誕生しました。BMWやKTMなどのグローバルメーカー向けのデザイン性・機能性にこだわったトップケースの商品開発に特化しており80年代にPIAGGIOEspana(ピアジオエスパーニャ)サプライをスタートさせたことでSHADは世界的なプロバイダーとなり、HONDA、YAMAHA、そしてSUZUKIといった日本メーカーへの商品提供が始まりました。続けて90年代にもPEUGEOT、BMW、MBK(YAMAHAFrance)など海外ビジネスパートナーを増やし、今では80ヵ国以上で愛用されているブランドです。

国際的に権威のある「世界三大デザイン賞」2賞を受賞。Red Dot Design Award と iF DESIGN AWARD 2021受賞をした唯一のバイク用トップケースです。
メーカー純正アルミケースや他社アルミケース以上に洗練されたデザインと、アルミボディによる強靭さ、SHADのノウハウを蓄積した利便性を備えているトップケースとなっております。
・設計から製造まで完全スペイン製
・本体は軽量で丈夫なアルミ素材、ロックシステムは頑丈なステンレスを使用
・アルミケース特有のリベット打ちやつなぎ目を極力抑えた、他社ケースとは一線を画すデザイン
・薄さ約1.2mmのアルミボディで軽量化
・アルミケース特有のロック部分の出っ張りがなく、セキュリティ万全なプレミアムキー
・キーシリンダーの統一でトップ＆サイドケースをワンキーで開閉が可能
・片手でスムーズな開閉と、ベースプレート脱着が可能
・ロック部分にはダストや砂などを防ぐ防塵キャップ付き
・持ち運びに便利なハンドル付き
・上下の蓋の接合部分には防水シーリング加工を施し、防水性能を発揮
・トップケース上蓋にはバッグを固定できるフックホルダー付き
・ケース内底部にはフォームベースを設置し積載物を保護
【About TERRA(テラ)】
「TERRA」はスペイン語で「地球」を意味します。母なる大地である地球に敬意を表して名付けられました。この惑星とその自然の豊かさは、すべてのオートバイ愛好家に冒険の無限の可能性を与えます。
そしてアルミケース「TERRA」は、ロングツーリングや旅行において最高の相棒となるよう設計されており、今まで以上に楽しいライディングを体験いただける事を保証します。タフな旅の味方として多くのライダーを満足させるのがこのTERRAシリーズです。

・TERRAシリーズのトップケースにはベースプレートが付属しておりません。TERRAシリーズのトップケースをご購入の方は、樹脂製ベースプレートD1B591PA(品番：27120064)か、アルミ製ベースプレートD1BTRPA(品番：19708751)・D1BTRPA2(品番：26773667)を併せてご購入いただく必要がございます。(いずれのベースプレートも、車種別フィッティングキットの適合をご確認の上お買い求めください)
・防水性を考慮した設計ですが、完全防水ではありません。
・スムーズな開閉を継続するためにキーシリンダー(鍵穴部分)に約半年(目安)に1回程度、防錆潤滑剤 でメンテナンスを行ってください。
【取付の前に】
走行中の脱落をより防止するため、ケース本体とベースプレートのクリアランスを少なめに調整しております。
初期段階ではかなり脱着が堅い状態になっておりますが馴染んでくればベストフィッティングとなります。
取付前にベースプレートに本体を取り付けた状態で約24時間置いて頂き、脱着を数回していただくことをお勧めいたします。
【取扱説明書について】
SHADの環境配慮の方針に伴い、紙面を付属させずデジタル化への切り替えを順次進めております。
取扱説明書が付属されていない場合につきましては、ケース内部にQRコード付きのステッカーがございます。
スマートフォンなどの端末で読み取っていただき取扱説明書サイトへアクセスいただきますよう、ご協力をお願いいたします。
