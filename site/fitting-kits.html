How It Mounts

装着は、3つの部品で完成する。

01

車種専用キット

02

ベースプレート
ワンタッチ脱着の受け皿

03

ケース／バッグ
載せてキーでロック

プラスチック製ケースはベースプレート付属。TERRAシリーズは別売です。

Top Case

Top Master

トップケースの土台は、車種ごとに違う。

車体の特性に合わせて個別に設計。だから仕上がりが美しく、着脱も簡単。

車種・年式ごとに専用品番 ベースプレートと組み合わせて装着

Side Case

3P / 4P System

サイドケースを、車体の一部に。

市場最大径の20mmスチール。ケースを外せばステーだけが残り、シルエットを崩しません。

20mm スチールフレーム 粉体塗装メタリック仕上げ 4Pはクロスバーで補強

3Pシステム

車体側に寄せた一体設計。軽さで重心変化を抑え、組み付けも簡単。

対応ケース
SH23 / SH35 / SH36 / SH38X / TR27 / TR30 / TR40

4Pシステム

TERRAのケース・バッグ用にバルセロナで開発。クロスバーで過酷な使用にも応える。

対応ケース
TR47 / TR36 / TR30 / TR40 / SH23 / SH35 / SH36 / SH38X

4Pに SH23・TR27 を装着する場合はアダプター D1TR27FIR が必要です。

車種に対応するサイドキットを探す

Side Bag

Side Bag Holder

ソフトバッグの位置を、走行中も保つ。

タイヤやマフラーへの接触を防ぐホルダー。車種専用・汎用・SRの3タイプ。

対応：TR30 / TR40 / E48 / SL58 / SR38

車種専用ホルダー

バッグの位置と角度が決まり、走行中のズレを防ぐ。

汎用ホルダー

専用キットが無い車種向け。

SRキット

クラシック／カフェレーサーにSRコレクションを。

Tank Bag

Click System

1秒で着けて、1秒で外す。

給油口まわりのリングで装着。バッグがタンクに触れないから、塗装も傷めません。

対応：TR15CL / TR10 / E09C / E09CL / E09CM / E03C / E03CL / E02C

Backrest

Backrest Kit

タンデムの快適性を、背もたれで。

スクーター用のほか、クラシック系の車体に合わせるタイプも。キットとあわせてバックレスト本体が必要です。

本体：D0RP00 / D0RP00N / D0RP05 / D0RP08

Handle Lock

Shad Locks

屈まない、汚れない。数秒の防犯。

SHADロックも車種ごとの取付キットで装着します。工具なしで施錠。

SHADロックを見る
