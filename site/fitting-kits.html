Fitting Kits

バイクとケースの間には、専用の設計がある。

フィッティングとは、バイクとケース・バッグをつなぐ取付部品のこと。SHADはケースやバッグと同時に取付キットまで自社で開発しています。だから車体のデザインを崩さず、すべての部品を確実に固定できます。

Why Fitting Matters

車種ごとの専用設計

キットは車種の形状と取付点に合わせて個別に設計されます。ボルトオンで確実に固定でき、着脱も簡単です。

車体に溶け込む一体感

ケースだけでなく取付部までデザインするから、装着してもシルエットが崩れません。積載は足しても、見た目は足さない。

安全な固定

ケース・バッグと取付キットを一体で開発・検証。走行中の荷重と振動を前提に、すべての部品の固定を保証します。

主要メーカーに対応する500点以上のキットを展開 取付ける商品の種類ごとにキットが異なります

How It Mounts

バイクとケースの間に入るのは、2つの部品。

トップケースを装着するには、車体に固定する「車種専用キット」と、ケースを受ける「ベースプレート」が必要です。この2つが決まれば、あとはケースを載せてロックするだけ。

01

車種専用フィッティングキット

車体に固定する土台。車種・年式ごとに品番が異なります。トップケースは「トップマスター」、サイドケースは「3P／4Pシステム」。

02

ベースプレート

キットの上に載せ、ケースをワンタッチで脱着できるようにする受け皿。プラスチック製ケースには付属し、TERRAシリーズは別売です。

03

ケース／バッグ

プレートに載せてロック。キーひとつで開閉・ロック・車体からの脱着までを一元管理できます。

Top Case

Top Master

車種ごとに設計された、トップケースの土台。

トップマスターは、トップケースを車体に取り付けるためのキットです。車種ごとの特性を踏まえて個別に設計されているため、仕上がりの美しさ・扱いやすさ・安全性が高く、着脱も簡単に行えます。

トップケースを装着するには、このキットに加えてベースプレートが必要です。プラスチック製ケースにはベースプレートと取付金具が付属しています（TERRAシリーズは別売）。

車種から必要なキットを調べる

Base Plates

ベースプレートはケースの底面を受け、ワンタッチでの脱着を可能にする部品です。サイズは3種類。大型ケースとTERRAシリーズ用には、軽量で剛性の高いアルミ製プレートも用意しています。

3P / 4P System

サイドケースを、車体の一部に。

サイドケースは、車体の左右にキットを組んで装着します。SHADには性格の異なる2つのシステムがあり、車種によって対応するシステムが決まります。ケースを外せばステーだけが残り、シルエットを崩しません。

20mm スチールフレーム（市場最大径） 粉体塗装のメタリック仕上げ

3Pシステム

SHADの重要な発明のひとつ。車体側に寄せた一体設計で、サイドキットとしての存在感を最小限に抑えます。

  • 一体設計：サイドキットが車体によりよく溶け込む
  • 軽量：重心の変化が小さく、安全性に寄与する
  • 組み付けが簡単
対応ケース
SH23 / SH35 / SH36 / SH38X / TR27 / TR30 / TR40

4Pシステム

TERRAのケースとサイドバッグを装着するため、バルセロナで100%設計・開発されたシステム。2つのケースの間をクロスバーで補強し、ハードな使い方に応えます。

  • 市場最厚の20mm径スチール構造による高い剛性と耐久性
  • クロスバーの補強で、過酷なツーリングにも対応
  • SH23 / SH35 / SH36 / SH38X のサイドケースにも対応
対応ケース
TR47 / TR36 / TR30 / TR40 / SH23 / SH35 / SH36 / SH38X

4Pシステムに SH23・TR27 のサイドケースを装着する場合は、アダプター D1TR27FIR が必要です。

Side Bag

Side Bag Holder

ソフトバッグの位置を、走行中も保つ。

サイドバッグは、タイヤやマフラーに接触しないよう専用のホルダーで位置を保って装着します。車種専用タイプ、汎用タイプ、カフェレーサー向けのSRタイプがあります。

車種専用ホルダー

車種ごとに設計されたホルダー。バッグの位置と角度が決まり、走行中のズレを防ぎます。

汎用ホルダー

専用キットが無い車種向け。車体に合わせて取り付けるタイプです。

SRキット

クラシック／カフェレーサー系の車体に、SRコレクションのバッグを合わせるキットです。

対応バッグ：TR30 / TR40 / E48 / SL58 / SR38 車種により対応ホルダーが異なります
Tank Bag

Click System

1秒で着けて、1秒で外す。

タンクバッグは、給油口まわりに取り付けるリング状のキットで装着します。ワンタッチで脱着でき、バッグがタンクに触れないため塗装を傷めません。車種専用リングと汎用タイプがあります。

対応：TR15CL / TR10 / E09C / E09CL / E09CM / E03C / E03CL / E02C
対応するリングを調べる
Backrest

Backrest Kit

タンデムの快適性を、背もたれで。

タンデム時の快適性を高めるバックレスト用のキットです。スクーター用のほか、クラシック・カスタム系の車体に合わせるタイプもあります。キットだけでは装着できないため、あわせてバックレスト本体をご用意ください。

SHADロックも、車種ごとの取付キットで装着します。日常の駐輪で、工具なしに数秒で施錠できます。
