適合・取り付け

Q自分のバイクに取り付けられますか？
あなたのバイクから探すでメーカー・車種・年式を選ぶと、適合する製品と必要な車種専用フィッティングキットが確認できます。万一適合が見つからない場合も、お問い合わせいただければお調べいたします。
Qトップケース（リアボックス）の取り付けにフィッティングキットは必要ですか？
リアキャリアが付いている場合は、リアボックスに付属する汎用ベースプレートで取り付けできます。汎用性の高いベースプレートを採用していますが、極太パイプキャリアや極小のデザインキャリアなど、一部特殊な形状では取り付けできない場合があります。キャリアがない車両やサイドケースは、車種専用フィッティングキットが必要です。
Q取り付けに加工は必要ですか？
フィッティングキット・ケース本体ともに、特殊な加工は必要ありません。ネジ・ボルト類の締め付け程度の作業で装着できます。※バックレストやパネル等を追加で装着する場合は加工が必要になることがあります。
Qケースの開け方・操作方法が分かりません。
サイズ・モデルにより操作方法が異なります。各製品ページに操作動画・ユーザーガイドを掲載していますのでご確認ください。取り付け手順は取付ガイドもご覧いただけます。
Q取扱説明書が見当たりません。
環境配慮の方針により、取扱説明書は順次デジタル化しています。ケース内部に貼付されたQRコードを読み取ると、取扱説明書サイトにアクセスできます。

製品について

QSHAD はどこの国のブランドですか？
1973年にスペイン・バルセロナで誕生したブランドです。国内外の有名車両メーカーの純正（OEM）も受注生産しており、いまでは世界60ヶ国以上で愛用されています。詳しくはブランドストーリーをご覧ください。
Q雨の日に使用しても大丈夫ですか？
ハードケースには最低限の防水設計が施されていますが、豪雨などシビアコンディションでのご使用をお考えの場合は、別途防水対策をおすすめします。高い防水性能が必要な場合は、TERRA の防水バッグもご検討ください。
Qヘルメットは収納できますか？
モデルにより異なります。各製品ページの容量・サイズ表記をご確認ください。たとえば可変容量サイドケース SH38X は、XLサイズのモジュラーヘルメット（ECE 22-06）の収納に対応します。
Q種類が多くて、どのケースを選べばよいか分かりません。
ご使用目的にもよりますが、目安として——原付二種まで：SH26〜SH33／中型：SH29〜SH45／大型：SH40〜SH58X、が選ばれています。車種適合検索で、お持ちのバイクに合うモデルから絞り込むのがおすすめです。
Qトップケースとサイドケースの鍵を1本にまとめられますか？
対応モデルでは、予備キーシリンダーへの交換により鍵を統一できます。鍵単体の作成はできず、シリンダーごとの交換が必要です。適合する補修シリンダーの品番は製品・サイズにより異なりますので、製品ページまたは取扱店でご確認ください。

購入・お届け

Qどこで購入できますか？
オンラインは、日本総代理店カスタムジャパンの公式EC（moto.customjapan.net）でご購入いただけます。実物をご覧になりたい場合はお近くの店舗、購入から取り付けまで一度に済ませたい場合は SHAD BASE をご利用ください。
Q価格を知りたいです。
各製品ページの「ご購入」に、本体およびフィッティングキットのメーカー希望小売価格を掲載しています。「購入する」ボタンから、カスタムジャパンECの該当商品ページ（販売価格・在庫）に進めます。
Q支払方法を教えてください。
カスタムジャパンECでは、クレジットカード（VISA / Mastercard / JCB / AMEX / Diners）・代金引換・まとめて支払いサービスがご利用いただけます。クレジットカードはWEBサイトからのご注文でご利用いただけます。詳細・最新の条件はご注文画面でご確認ください。
Q送料はかかりますか？
送料は一律300円（税別）、代金引換手数料は一律350円（税別）です。北海道は別途500円（税別）、沖縄・一部地域は別途1,000円（税別）の特別配送料金がかかります。最新の送料・条件はカスタムジャパンECのご注文画面をご確認ください。
Q商品はいつ届きますか？
商品ごとに出荷目安（納期アイコン）が異なります。複数同時にご注文の場合は、最も納期の遅い商品に合わせてまとめて出荷されます。欠品時はメール等でご連絡します。
Q注文後にキャンセル・変更はできますか？
ご注文完了後15分間は、カスタムジャパンECのマイページから無条件でキャンセル・内容変更が可能です。15分を過ぎると発送準備に入るため、取寄品など一部はキャンセル・変更ができなくなる場合があります。

返品・交換

Q返品はできますか？
商品到着後30日以内にカスタムジャパンへご連絡ください。ただし開封済・使用済の商品、取寄商品、純正商品など、返品・交換できない商品は除きます。お客様のご都合による返品の場合、送料等の諸費用はお客様のご負担となります。返送時は弊社より回収の手配をいたしますので、ご連絡なしでの返送はお控えください。
Q商品の交換はできますか？
お客様都合による交換は、いったん返品として承り、ご希望の商品を新規にご注文いただく形となります。お届けまでにお時間をいただく場合があります。
Q届いた商品に不具合・破損がありました。
カスタムジャパンのお問い合わせフォームまたはお電話で、状態と不具合の詳細をご連絡ください。輸送中の外装破損などは、運送会社が良品とのお取り替えに伺います。車両情報や状況を添えていただくと、ご案内がスムーズです。

保証・修理

Q保証はありますか？
商品により内容の異なる保証サービスがあります。詳細は故障・不具合の内容とあわせてお問い合わせください。なお、ご購入時に同梱されている色紙が製品の識別番号となりますので、お問い合わせの際にご準備ください。詳しくは保証についてをご覧ください。
Q壊れたら修理できますか？
恐れ入りますが、修理のお受付は行っておりません。製品によっては関連パーツ単体のお取り扱いがありますので、交換でご対応いただけます。
Q補修部品（キーシリンダー等）は購入できますか？
キーシリンダーやマウント部品など、一部のパーツは補修部品としてお取り扱いがあります。適合する品番は製品・サイズにより異なりますので、カスタムジャパンEC または取扱店でご確認ください。

店舗・SHAD BASE

Q実物を見たいのですが、どこで見られますか？
SHAD BASE（体験拠点）やお近くの取扱店で展示しています。店舗検索から、地図・エリア・現在地で展示店・SHAD BASE を探せます。展示の有無は店舗により異なります。
QSHAD BASE とは何ですか？
SHAD BASE は、製品の購入から商品の取り付けまで対応する体験拠点です。「お近くの店舗」は、実物の展示やお取り寄せに対応する取扱店です。

解決しませんでしたか？

お近くの取扱店・SHAD BASE、またはカスタムジャパンのお問い合わせ窓口へお気軽にご相談ください。
